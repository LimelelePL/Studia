# Kalkulator pola trójkąta

Program do obliczania pola trójkąta z walidacją danych wejściowych.

---

## Wymagania

- [uv](https://docs.astral.sh/uv/)

---

## Instalacja

```bash
git clone <repo>
cd <repo>
uv sync
```

## Uruchomienie

```bash
uv run main.py
```

---

## Narzędzia

### Ruff

Linter i formatter kodu. Łapie błędy, unused imports, złe praktyki i formatuje kod.

```bash
uv run ruff check .       # sprawdź błędy
uv run ruff check . --fix # napraw automatycznie
uv run ruff format .      # sformatuj kod
```

### Mypy

Sprawdza poprawność typów — czy funkcje dostają argumenty właściwego typu.

```bash
uv run mypy .
```

## Zarządzanie zależnościami (uv)

```bash
uv add <pakiet>            # dodaj pakiet
uv add <pakiet> --dev      # dodaj pakiet tylko na development
uv remove <pakiet>         # usuń pakiet
uv sync                    # zainstaluj wszystkie zależności z uv.lock
uv run <komenda>           # uruchom komendę w środowisku projektu
```

> `uv.lock` zawsze commituj do gita — zapewnia identyczne wersje pakietów na każdej maszynie.
> `.venv` nigdy nie commituj — jest generowany automatycznie przez `uv sync`.
